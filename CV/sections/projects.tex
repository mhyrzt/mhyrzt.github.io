\section{Selected Projects}
\begin{projectentry}{OGym --- Rust reinforcement-learning environments}{https://github.com/mhyrzt/ogym}
Built a Rust library of reinforcement-learning environments with typed action and observation spaces, a shared environment interface, and batch execution. Implemented environments using native Rust, Rapier, and MuJoCo, with reproducible benchmarks against Gymnasium.
\end{projectentry}

\begin{projectentry}{XRAT --- proxy management and runtime tooling}{https://github.com/mhyrzt/xrat}
Built a Rust toolkit for testing and managing proxy connections, with command-line, terminal, and web interfaces. Implemented concurrent latency testing, connection monitoring, and automatic rotation, with a reusable SDK for configuration parsing and generation.
\end{projectentry}

\begin{projectentry}{Mahfel --- real-time meetings and collaboration}{https://github.com/mhyrzt/mahfel}
Developed Rust services and a Next.js interface for WebRTC meetings and collaboration, integrating media, signaling, background jobs, and shared storage.
\end{projectentry}

\begin{projectentry}{Android Facial Landmark Detection}{https://github.com/mhyrzt/Dlib-Android-Face-Landmark}
Built an Android application for 68-point facial landmark detection, integrating dlib's C++ implementation with Java through the Android NDK, CMake, and OpenCV.
\end{projectentry}
