# [mhyrzt.github.io](https://mhyrzt.github.io)

built using [Tailwind CSS](https://tailwindcss.com/) and the CMU font by [Steven Petryk](https://github.com/stevenpetryk/computer-modern).

## CV

CV sources and local `just` commands are in [`CV/`](CV/README.md).
Push a `cv-YYYY-MM-DD-HH-mm` tag to build and publish all three PDFs as a
[GitHub Release](https://github.com/mhyrzt/mhyrzt.github.io/releases).
